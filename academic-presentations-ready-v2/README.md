# Academic Presentations — Rodrigo A. Garrido

Static website for conference presentations and academic biography.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `academic-presentations` under `rodrigogarridohidalgo` (do not initialize with a README).
2. Upload the contents of this folder at the **root** of the repository, preserving `downloads/` and `assets/`. You may use **Add file → Upload files** in GitHub.
3. Open repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. Site: https://rodrigogarridohidalgo.github.io/academic-presentations/
5. Verify the site and scan the QR code after GitHub Pages has deployed.

## Add the Long Beach presentation

Upload the file as `downloads/CSULB_Garrido_2026.pptx`, then replace the second card in `index.html` with a download link and final title. The website URL and QR code will not change.

## Privacy and maintenance

Anything committed to this public repo (including the PowerPoint and CV) is publicly accessible. The 2025 short bio was used as background but is not published because its institutional details are outdated. The published CV contains contact information; review it before uploading if necessary. Avoid adding private phone numbers to the landing page.
